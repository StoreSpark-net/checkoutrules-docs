## Visión general de la regla

Esta regla te permite renombrar, o añadir un prefijo, sufijo o traducir métodos de pago en el checkout según condiciones definidas. Puedes personalizar cómo se muestran las etiquetas de los métodos de pago usando criterios como valor del carrito, dirección de envío, etiquetas de cliente, detalles del producto y más.

Esto ayuda a mejorar la claridad, apoyar la localización y mejorar la experiencia general de checkout para los clientes.

## Configuración de ejemplo

Los siguientes pasos muestran cómo crear y configurar una regla **Renombrar Métodos de Pago** usando la aplicación.

### Crear una nueva regla

Desde tu [admin de Shopify](/guides/es/get-started/installation#ir-a-la-aplicación), abre la aplicación. En la barra lateral, ve a la sección [Reglas](/guides/es/get-started/quickstart#crear-una-regla-de-ejemplo) y haz clic en _"Crear Regla"_.

Luego, serás redirigido a la pantalla **Seleccionar tipo de regla de checkout**. Elige _categoría "Pago" → selecciona tipo de regla de checkout "Renombrar Métodos de Pago" → haz clic en "Seleccionar Regla"_.

<img
  src="/images/essentials/payment/select-rename-payment-methods.webp"
  alt="Select Rename Payment Methods"
/>

A continuación, llegarás a la pantalla **Crear nueva regla de renombrar métodos de pago**, donde puedes configurar tu regla.

### Configuración de regla

Para configurar la regla, primero opcionalmente podemos añadir un nombre como "Renombrar métodos de pago" para describir lo que hace. Luego, selecciona el [estado](/guides/es/get-started/concepts#estado) de la regla: Prueba, Activo o Desactivado.

Aquí vamos a elegir el estado **Prueba**, para que podamos probar rápidamente la regla sin afectar el checkout para clientes reales.

<img
  src="/images/essentials/payment/rule-configure-1-rename-payment-methods.webp"
  alt="Rule Configure 1"
/>

A continuación, en la misma pantalla, selecciona el [conjunto de condiciones](/guides/es/get-started/concepts#conjunto-de-condiciones), [condición](/guides/es/get-started/concepts#condiciones-el-cuándo) y [acción](/guides/es/get-started/concepts#acción-el-qué) relevantes.

> Como ejemplo, estamos usando el **Conjunto de condiciones 1**, configurando la regla para ejecutarse **Siempre**, y configurándola para renombrar el método de pago **"Contra Entrega (COD)"** a **"Pagar en Efectivo"**.

**Renombrar estos métodos de pago** con operadores de coincidencia de nombre de método: **contiene**, **no contiene**, **es**, **no es**.

Para cada método coincidente, elige un modo de salida:

- **Renombrar a**: reemplaza completamente el nombre del método.
- **Añadir prefijo**: añade texto personalizado antes del nombre original del método.
- **Añadir sufijo**: añade texto personalizado después del nombre original del método.

<Note>
  Para la coincidencia de nombres de método en esta regla:

    - La coincidencia no distingue entre mayúsculas y minúsculas.
    - El comodín `*` es compatible en la entrada del usuario (por ejemplo: `Standard*`, `*Express*`, `*Pickup`).
    - **contiene** / **no contiene** usan coincidencia parcial.
    - **es** / **no es** admiten texto exacto y patrones de comodín.
    - Si añades varias filas de métodos, se evalúan como OR (cualquier fila coincidente puede aplicarse).

</Note>

<img
  src="/images/essentials/payment/condition-set-rename-payment-methods.webp"
  alt="Condition Set Rename Payment Methods"
/>

Opcionalmente, puedes agregar traducciones para **renombrar**, **prefijo** y **sufijo** haciendo clic en el **icono de agregar traducción**.

<img
  src="/images/essentials/payment/rename-payment-translation-icon.webp"
  alt="Icono de traducción"
/>

Luego selecciona un idioma del menú desplegable e ingresa el mensaje traducido para el idioma seleccionado. El texto ingresado en la primera fila se utilizará como texto predeterminado y se mostrará cuando no haya una traducción disponible.

<img
  src="/images/essentials/payment/rename-payment-translation.webp"
  alt="Traducción"
/>

También puedes agregar múltiples traducciones haciendo clic en el botón **Agregar traducción** y repitiendo el mismo proceso para cada idioma.

<img
  src="/images/essentials/payment/rename-payment-multiple-translations.webp"
  alt="Múltiples traducciones"
/>

Finalmente, haz clic en el botón <b>Guardar</b> en la parte superior para crear y guardar tu regla.

<img src="/images/shared/save-rule.webp" alt="Rule Save" />

## Probar la regla

Como la regla está configurada en estado de prueba, tenemos que usar `test@testing.com` como el email, en lugar del email real, para ejecutar la regla en el checkout.

<Warning>
  La imagen de abajo muestra la página de checkout <b>antes</b> de que se usara la dirección de email
  de prueba. Por favor nota que el método de pago Contra Entrega (COD) aún no está
  renombrado.
</Warning>

<img
  src="/images/essentials/payment/before-rule-apply-payment-methods.webp"
  alt="Before Rule Apply"
/>

Después de configurar el email, la regla de checkout se ejecuta y renombra los métodos de pago especificados. Podemos verificar que el método de pago **"Contra Entrega (COD)"** ahora se muestra como **"Pagar en Efectivo"**, como se muestra a continuación.

<img
  src="/images/essentials/payment/after-rule-apply-rename-payment-methods.webp"
  alt="After Rule Apply"
/>

## Activar la regla

Una vez que las pruebas estén hechas, podemos activar la regla, para que pueda comenzar a hacer cambios al checkout para clientes reales. Solo las reglas activadas pueden hacer cambios al checkout para todos los clientes.

Haz clic en **Reglas** en la barra lateral para ver todas las reglas. Selecciona la regla que quieres activar, luego haz clic en el botón **Activar** para activarla.

<Warning>
  La activación de reglas solo está disponible en planes pagos. Si no has actualizado tu
  plan aún, sigue las instrucciones
  [aquí](/guides/es/get-started/installation#actualizar-tu-plan) para actualizar.
</Warning>
<img
  src="/images/essentials/payment/activate-the-rule-rename-payment-methods.webp"
  alt="Activate The Rule"
/>

## Limitaciones

- Los métodos de pago que solo tienen logo no se pueden renombrar.
- PayPal, Amazon Pay, Shop Pay y algunos otros métodos de pago no se pueden renombrar.
- Para tiendas en EE.UU./Canadá, la opción de tarjeta de crédito no se puede cambiar, a menos que esté en Shopify Plus. Esta limitación proviene de Shopify.
